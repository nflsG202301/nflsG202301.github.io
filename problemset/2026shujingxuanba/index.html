一、填空题（每小题 8 分，共 64 分）
  1. 设数列 \(\{a_n\}\) 的前 \(n\) 项和为 \(S_n\)，若 \(S_n + (-1)^n a_n = n^2 - 1\)，则 \(a_1 = \underline{\qquad}\)。
  2. 从 \(1, 2, 3, 4, 5, 6\) 中随机选取 3 个不同的数组成一个三位数，则这个三位数能被 3 整除但不能被 5 整除的概率为 \(\underline{\qquad}\)。
  3. 设椭圆 \(\dfrac{x^2}{9} + \dfrac{y^2}{5} = 1\) 的左、右焦点分别为 \(F_1, F_2\)，\(A\) 是其上一点，满足 \(\cos \angle AF_2F_1 = \dfrac{1}{4}\)，则 \(\triangle AF_1F_2\) 的面积为 \(\underline{\qquad}\)。
  4. 过半径为 5 的球面上一点 \(P\) 作三条两两垂直的弦 \(PA, PB, PC\)，且满足 \(PA = 2PB\)，则 \(PA + PB + PC\) 的最大值为 \(\underline{\qquad}\)。
  5. 实数集合 \(S = \{-3, -2, -1, 1, e, \pi\}\)，它的非空子集为 \(S_1, S_2, \dots, S_{63}\)，设 \(S_i\) 中所有元素的乘积为 \(s_i\)，\(i = 1, 2, \dots, 63\)，则 \(s_1 + s_2 + \dots + s_{63} = \underline{\qquad}\)。
  6. 设 \(x \in (0, \pi)\)，则函数 \(f(x) = \dfrac{(\sin x)^3}{1 + \cos x} + \dfrac{(\cos x)^3}{1 + \sin x}\) 的值域为 \(\underline{\qquad}\)。
  7. 已知平面单位向量 \(\boldsymbol{a}, \boldsymbol{b}, \boldsymbol{c}, \boldsymbol{x}\)，且 \(\boldsymbol{a} + \boldsymbol{b} + \boldsymbol{c} = \boldsymbol{0}\)。记 \(y = |\boldsymbol{x} - \boldsymbol{a}| + |\boldsymbol{x} - \boldsymbol{b}| + |\boldsymbol{x} - \boldsymbol{c}|\)，则 \(y\) 的最大值为 \(\underline{\qquad}\)。
  8. 已知正实数 \(a, b\) 满足 \(a + b = 6\)，则 \(\dfrac{a}{a^2 + 1} + \dfrac{b}{b^2 + 1}\) 的最大值为 \(\underline{\qquad}\)。
二、解答题（第 9 小题 16 分，第 10、11 小题 20 分，共 56 分）
  1. 在 \(\triangle ABC\) 中，\(\sin A \cos B + \sin B \cos C + \sin C \cos A = \dfrac{1}{2}(\sin A + \sin B + \sin C)\)。试判断 \(\triangle ABC\) 的形状，并说明理由。
  2. 已知复数 \(z\) 满足 \(|z| = 1\)，试求 \(|z^3 - 3z - 2|\) 的最大值。
  3. 已知 \(P\) 是以椭圆 \(\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1\) 的长轴为直径的圆上任一点（异于椭圆顶点），\(PA, PB\) 分别与椭圆相切于点 \(A\) 和 \(B\)，求 \(\triangle OAB\) 面积的最大值（其中 \(O\) 为坐标原点）。
第 1 题 答案：\(a_1 = 13\)

分别取 \(n=1,2,3\) 代入。

\(n=1\)：\(S_1 - a_1 = 0\)，即 \(a_1 - a_1 = 0\)，恒成立，无法直接求出 \(a_1\)。

\(n=2\)：\(S_2 + a_2 = 3\)，即 \((a_1+a_2)+a_2 = 3\)，得 \(a_1 + 2a_2 = 3\)。

\(n=3\)：\(S_3 - a_3 = 8\)，即 \((a_1+a_2+a_3)-a_3 = 8\)，得 \(a_1+a_2 = 8\)。

联立两式相减得 \(a_2 = -5\)，代回得 \(a_1 = 13\)。

第 2 题 答案：\(\dfrac{1}{3}\)

总三位数个数为 \(\mathrm{A}_6^3 = 120\)。

能被 3 整除的组合有 \((1,2,3)\)、\((1,2,6)\)、\((1,3,5)\)、\((1,5,6)\)、\((2,3,4)\)、\((2,4,6)\)、\((3,4,5)\)、\((4,5,6)\)，共 8 组，每组可排列成 \(3! = 6\) 个三位数，共 \(48\) 个。

其中能被 5 整除的末位为 5。含 5 的组合有 4 组，5 固定末位后前两位有 \(2! = 2\) 种，共 \(8\) 个。

故满足条件的有 \(48 - 8 = 40\) 个，概率为 \(\dfrac{40}{120} = \dfrac{1}{3}\)。

第 3 题 答案：\(\sqrt{15}\)

椭圆中 \(a=3,\ b=\sqrt{5},\ c=2\)，焦距 \(F_1F_2 = 4\)。

设 \(AF_1=m,\ AF_2=n\)，由椭圆定义 \(m+n=6\)。

在 \(\triangle AF_1F_2\) 中，由余弦定理：

\(m^2 = n^2 + 16 - 8n \cdot \dfrac{1}{4} = n^2 + 16 - 2n\)。

又 \(m = 6-n\)，代入得 \((6-n)^2 = n^2 + 16 - 2n\)，解得 \(n=2,\ m=4\)。

面积 \(S = \dfrac{1}{2} mn \sin\angle AF_2F_1 = \dfrac{1}{2} \cdot 4 \cdot 2 \cdot \dfrac{\sqrt{15}}{4} = \sqrt{15}\)。

第 4 题 答案：\(2\sqrt{70}\)

\(PA, PB, PC\) 两两垂直，构成内接于球的长方体的三条棱，体对角线为球的直径 10，因此

\(PA^2 + PB^2 + PC^2 = 100\)。又 \(PA = 2PB\)，得 \(5PB^2 + PC^2 = 100\)。

设 \(PB = 2\sqrt{5}\cos\alpha,\ PC = 10\sin\alpha\)，则

\(PA + PB + PC = 6\sqrt{5}\cos\alpha + 10\sin\alpha = 2\sqrt{70}\sin(\alpha + \varphi) \le 2\sqrt{70}\)。

等号可取，最大值为 \(2\sqrt{70}\)。

第 5 题 答案：\(-1\)

考虑多项式 \(\displaystyle\prod_{x\in S}(1+x) = (1-3)(1-2)(1-1)(1+1)(1+e)(1+\pi)\)。

展开后每项对应 \(S\) 的一个子集，常数项 \(1\) 对应空集，其余项之和对应所有非空子集的乘积之和。

计算得 \((-2)(-1)(0)(2)(1+e)(1+\pi) = 0\)。

故所有非空子集的乘积之和为 \(0 - 1 = -1\)。

第 6 题 答案：\([\sqrt{2}-1,\ 1)\)

利用 \(\sin^3 x = \sin x (1 - \cos x)(1 + \cos x)\)，得

\(\dfrac{\sin^3 x}{1 + \cos x} = \sin x - \sin x\cos x\)，同理 \(\dfrac{\cos^3 x}{1 + \sin x} = \cos x - \sin x\cos x\)。

因此 \(f(x) = \sin x + \cos x - 2\sin x\cos x\)。

令 \(t = \sin x + \cos x \in (1, \sqrt{2}]\)，则 \(2\sin x\cos x = t^2 - 1\)，于是 \(f = -t^2 + t + 1\)。

对称轴 \(t = \dfrac{1}{2}\)，在 \(t \in (1, \sqrt{2}]\) 上单调递减，值域为 \([\sqrt{2}-1,\ 1)\)。

第 7 题 答案：\(4\)

由 \(\boldsymbol{a} + \boldsymbol{b} + \boldsymbol{c} = \boldsymbol{0}\) 且均为单位向量，知 \(\boldsymbol{a}, \boldsymbol{b}, \boldsymbol{c}\) 两两夹角 \(120^\circ\)，构成单位圆上的等边三角形。

当 \(\boldsymbol{x} = -\boldsymbol{a}\) 时：

\(|\boldsymbol{x} - \boldsymbol{a}| = 2\)，\(|\boldsymbol{x} - \boldsymbol{b}| = |\boldsymbol{c}| = 1\)，\(|\boldsymbol{x} - \boldsymbol{c}| = |\boldsymbol{b}| = 1\)。

故 \(y = 2 + 1 + 1 = 4\)，为最大值。

第 8 题 答案：\(\dfrac{\sqrt{10} + 1}{6}\)

令 \(b = 6 - a\)，求 \(f(a) = \dfrac{a}{a^2+1} + \dfrac{6-a}{(6-a)^2+1}\) 的最大值。

求导并令 \(g(x) = \dfrac{1-x^2}{(x^2+1)^2}\)，极值点满足 \(g(a) = g(b)\)，即

\((1-a^2)(b^2+1)^2 = (1-b^2)(a^2+1)^2\)。

约去 \(b^2 - a^2\)（\(a \ne b\)），得 \(a^2 + b^2 + 3 = a^2b^2\)。

设 \(p = ab\)，则 \(a^2 + b^2 = 36 - 2p,\ a^2b^2 = p^2\)，代入得 \(p^2 + 2p - 39 = 0\)，

解得 \(p = 2\sqrt{10} - 1\)（取正）。

再计算：

\(f = \dfrac{(a+b)(ab+1)}{a^2b^2 + a^2 + b^2 + 1} = \dfrac{6(p+1)}{p^2 - 2p + 37}\)。

代入 \(p = 2\sqrt{10} - 1\)，得 \(f = \dfrac{12\sqrt{10}}{80 - 8\sqrt{10}} = \dfrac{\sqrt{10} + 1}{6}\)。

第 9 题 答案：等边三角形

两边乘以 2 并利用 \(2\sin A\cos B = \sin C + \sin(A-B)\)，化简得

\(\sin(A-B) + \sin(B-C) + \sin(C-A) = 0\)。

设 \(u = A-B,\ v = B-C,\ w = C-A\)，则 \(u + v + w = 0\)，且

\(\sin u + \sin v + \sin w = 4\sin\dfrac{u+v}{2}\sin\dfrac{v+w}{2}\sin\dfrac{w+u}{2} = 0\)。

即 \(\sin\dfrac{w}{2}\sin\dfrac{u}{2}\sin\dfrac{v}{2} = 0\)。因 \(A,B,C \in (0,\pi)\)，得 \(u,v,w\) 中至少一个为 0，结合 \(u+v+w=0\) 推出 \(u=v=w=0\)。

故 \(A = B = C\)，\(\triangle ABC\) 为等边三角形。

第 10 题 答案：\(3\sqrt{3}\)

设 \(z = e^{i\theta}\)。计算模的平方：

\(|z^3 - 3z - 2|^2 = 14 - 6\text{Re}(z^2) - 4\text{Re}(z^3) + 12\text{Re}(z)\)。

令 \(t = \cos\theta\)，则 \(\text{Re}(z^2) = 2t^2 - 1,\ \text{Re}(z^3) = 4t^3 - 3t\)，代入得

\(h(t) = 20 + 24t - 12t^2 - 16t^3,\ t \in [-1, 1]\)。

求导 \(h'(t) = -24(2t-1)(t+1)\)，临界点 \(t = -1,\ \dfrac{1}{2}\)。

计算：\(h(-1) = 0,\ h(\tfrac{1}{2}) = 27,\ h(1) = 16\)。最大值为 27。

故 \(|z^3 - 3z - 2|_{\max} = \sqrt{27} = 3\sqrt{3}\)。

第 11 题 答案：\(\dfrac{3}{2}\)

设 \(P(x_0, y_0)\)，由极线方程得 \(AB\) 所在直线为

\(\dfrac{x_0 x}{4} + \dfrac{y_0 y}{3} = 1\)。

由于对称性，只需考虑 \(P\) 在 \(x\) 轴上方的情形，即 \(y_0 > 0\)。

此时 \(AB\) 与 \(y\) 轴交点 \(M\) 为 \(\left(0, \dfrac{3}{y_0}\right)\)，所以 \(OM = \dfrac{3}{y_0}\)。

联立方程组：

\(\begin{cases}\dfrac{x_0 x}{4} + \dfrac{y_0 y}{3} = 1\\[6pt] \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1\\[6pt] x_0^2 + y_0^2 = 4\end{cases}\)

消去 \(y\) 并整理得关于 \(x\) 的一元二次方程

\((y_0^2 + 12)x^2 - 24x_0 x + 48 - 16y_0^2 = 0\)。

设两根为 \(x_A, x_B\)，则

\(\Delta x = |x_A - x_B| = \dfrac{\sqrt{(24x_0)^2 - 4(y_0^2+12)(48-16y_0^2)}}{y_0^2+12} = \dfrac{8y_0^2}{y_0^2+12}\)。

故

\(S = \dfrac{1}{2}\,\Delta x \cdot OM = \dfrac{1}{2} \cdot \dfrac{8y_0^2}{y_0^2+12} \cdot \dfrac{3}{y_0} = \dfrac{12y_0}{y_0^2+12} = \dfrac{12}{y_0 + \dfrac{12}{y_0}}\)。

由于 \(P\) 在圆 \(x^2 + y^2 = 4\) 上，故 \(y_0 \in (0, 2]\)。当 \(y_0 \in (0, 2]\) 时，函数 \(y_0 + \dfrac{12}{y_0}\) 单调递减（因 \(y_0 < \sqrt{12}\)），所以它在 \(y_0 = 2\) 处取得最小值 \(2 + 6 = 8\)，对应 \(S\) 的最大值：

\(S_{\max} = \dfrac{12}{8} = \dfrac{3}{2}\)。

（当 \(y_0 = 2\) 时，\(x_0 = 0\)，\(P = (0, 2)\)，此时 \(AB\) 为 \(y = \dfrac{3}{2}\)，\(A = (1, \tfrac{3}{2})\)，\(B = (-1, \tfrac{3}{2})\)，验证 \(S = \dfrac{1}{2} \cdot 2 \cdot \dfrac{3}{2} = \dfrac{3}{2}\)。）
