试题 共 \(19\) 题
一、写出下列反应的离子方程式
  1. 用烧碱溶液吸收少量 \(\ce{SO2}\)。
  2. 实验室制 \(\ce{CO2}\)。
  3. \(\ce{Ba(OH)2}\) 溶液与稀硫酸混合。
  4. 向 \(\ce{AgNO3}\) 溶液中加入铜粉。
  5. 用稀硫酸除铁锈。
  6. 醋酸与氨水混合。
  7. \(\ce{NaHSO4}\) 溶液与小苏打溶液混合。
  8. 向 \(\ce{NH4HCO3}\) 溶液中加入足量烧碱后微热。
  9. 向 \(\ce{NaHCO3}\) 溶液中滴加少量澄清石灰水。
  10. 向石灰水中通入足量 \(\ce{CO2}\)。
  11. 醋酸与水垢中的氢氧化镁反应。
  12. 四氧化三铁溶于浓盐酸。
  1. 醋酸溶液中加入碳酸氢铵溶液。
  2. 向 \(\ce{NH4HSO4}\) 稀溶液中逐滴加入 \(\ce{Ba(OH)2}\) 稀溶液至刚好沉淀完全。
  3. 氢氧化钙溶液与碳酸氢钙溶液以任意比混合。
  4. 向饱和碳酸钠溶液中通入足量 \(\ce{CO2}\)。
  5. \(\ce{NaHSO4}\) 与 \(\ce{Ba(OH)2}\) 混合至中性；在上述中性溶液中继续滴加 \(\ce{Ba(OH)2}\) 溶液。
  6. 碱式碳酸铜 \(\ce{Cu2(OH)2CO3}\) 溶于足量稀盐酸。
  7. 下列方程式中的 \(\ce{G}\)、\(\ce{Q}\)、\(\ce{X}\)、\(\ce{Y}\)、\(\ce{Z}\) 为含有不同价态的氯元素的物质，它们之间存在如下反应：
    • （\(1\)）\(\ce{Y + NaOH -> G + Q + H2O}\)；
    • （\(2\)）\(\ce{G -> Q + NaCl}\)；
    • （\(3\)）\(\ce{Q + H2O -> X + H2 ^}\)；
    • （\(4\)）\(\ce{Z + NaOH -> Q + X + H2O}\)。

    试推断五种物质中氯元素的化合价由低到高的顺序为 　　　　　　（用 \(\ce{G}\)、\(\ce{Q}\)、\(\ce{X}\)、\(\ce{Y}\)、\(\ce{Z}\) 表示）。

第 \(1\) 题 答案：\(\ce{2OH- + SO2 -> SO3^2- + H2O}\)

\(\ce{SO2}\) 少量、\(\ce{NaOH}\) 足量，生成正盐 \(\ce{SO3^2-}\)。\(\ce{NaOH}\) 是可溶强碱，拆成离子；\(\ce{SO2}\) 是气体，不拆。

第 \(2\) 题 答案：\(\ce{CaCO3 + 2H+ -> Ca^2+ + H2O + CO2 ^}\)

实验室用大理石与稀盐酸反应。\(\ce{CaCO3}\) 难溶，写化学式；\(\ce{HCl}\) 是强酸，拆成 \(\ce{H+}\)；生成的 \(\ce{H2CO3}\) 立即分解为 \(\ce{H2O}\) 和 \(\ce{CO2}\)。

第 \(3\) 题 答案：\(\ce{Ba^2+ + 2OH- + 2H+ + SO4^2- -> BaSO4 v + 2H2O}\)

\(\ce{Ba(OH)2}\) 与 \(\ce{H2SO4}\) 都是强电解质，全部拆成离子。生成 \(\ce{BaSO4}\) 沉淀和水。

第 \(4\) 题 答案：\(\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}\)

置换反应。\(\ce{Cu}\) 是单质，写化学式；\(\ce{AgNO3}\) 是可溶盐，拆成 \(\ce{Ag+}\)；生成的 \(\ce{Ag}\) 是单质，写化学式。

第 \(5\) 题 答案：\(\ce{Fe2O3 + 6H+ -> 2Fe^3+ + 3H2O}\)

铁锈主要成分 \(\ce{Fe2O3}\)，不溶于水，写化学式；\(\ce{H2SO4}\) 拆成 \(\ce{H+}\)；生成的 \(\ce{Fe2(SO4)3}\) 可溶，拆成 \(\ce{Fe^3+}\)。

第 \(6\) 题 答案：\(\ce{CH3COOH + NH3.H2O -> NH4+ + CH3COO- + H2O}\)

\(\ce{CH3COOH}\) 是弱酸、\(\ce{NH3.H2O}\) 是弱碱，两者都不拆，直接写化学式。生成强电解质 \(\ce{CH3COONH4}\)，拆成离子。

第 \(7\) 题 答案：\(\ce{H+ + HCO3- -> H2O + CO2 ^}\)

\(\ce{NaHSO4}\) 是强酸的酸式盐，在水中完全电离出 \(\ce{H+}\)；\(\ce{NaHCO3}\) 中的 \(\ce{HCO3-}\) 是弱酸酸根，不拆。

第 \(8\) 题 答案：\(\ce{NH4+ + HCO3- + 2OH- -> NH3 ^ + CO3^2- + 2H2O}\)

\(\ce{NaOH}\) 是足量的，所以 \(\ce{NH4+}\) 和 \(\ce{HCO3-}\) 都要反应完，各消耗 \(1\) 个 \(\ce{OH-}\)，共需 \(2\) 个 \(\ce{OH-}\)。微热条件下生成 \(\ce{NH3}\) 气体逸出。

若 \(\ce{NaOH}\) 少量，则只有 \(\ce{HCO3-}\) 先反应：\(\ce{HCO3- + OH- -> CO3^2- + H2O}\)。

第 \(9\) 题 答案：\(\ce{2HCO3- + Ca^2+ + 2OH- -> CaCO3 v + CO3^2- + 2H2O}\)

石灰水少量，\(\ce{Ca(OH)2}\) 按 \(1:2\) 完全消耗（\(1\) 个 \(\ce{Ca^2+}\)、\(2\) 个 \(\ce{OH-}\)）。\(\ce{NaHCO3}\) 过量，所以只消耗 \(2\) 个 \(\ce{HCO3-}\)，生成 \(1\) 个 \(\ce{CaCO3}\) 沉淀和 \(1\) 个 \(\ce{CO3^2-}\)。

对比：若石灰水过量，则反应为 \(\ce{Ca^2+ + OH- + HCO3- -> CaCO3 v + H2O}\)。

第 \(10\) 题 答案：\(\ce{OH- + CO2 -> HCO3-}\)

\(\ce{CO2}\) 足量时，先生成的 \(\ce{CaCO3}\) 会继续与 \(\ce{CO2}\)、\(\ce{H2O}\) 反应生成可溶的 \(\ce{Ca(HCO3)2}\)，两步合并后净反应只剩 \(\ce{OH-}\) 与 \(\ce{CO2}\) 生成 \(\ce{HCO3-}\)。

第 \(11\) 题 答案：\(\ce{2CH3COOH + Mg(OH)2 -> Mg^2+ + 2CH3COO- + 2H2O}\)

\(\ce{Mg(OH)2}\) 难溶，写化学式、不能拆成 \(\ce{Mg^2+}\) 和 \(\ce{OH-}\)；\(\ce{CH3COOH}\) 是弱酸也不拆；生成的 \(\ce{(CH3COO)2Mg}\) 可溶，拆成离子。

第 \(12\) 题 答案：\(\ce{Fe3O4 + 8H+ -> Fe^2+ + 2Fe^3+ + 4H2O}\)

\(\ce{Fe3O4}\) 可看作 \(\ce{FeO.Fe2O3}\)，其中 \(\ce{Fe}\) 有 \(+2\) 和 \(+3\) 两种价态，与盐酸反应后分别生成 \(\ce{Fe^2+}\) 和 \(\ce{Fe^3+}\)。注意配平：\(1\) 个 \(\ce{Fe3O4}\) 对应 \(8\) 个 \(\ce{H+}\)、\(1\) 个 \(\ce{Fe^2+}\)、\(2\) 个 \(\ce{Fe^3+}\)、\(4\) 个 \(\ce{H2O}\)。

第 \(13\) 题 答案：\(\ce{CH3COOH + HCO3- -> CH3COO- + H2O + CO2 ^}\)

\(\ce{CH3COOH}\) 是弱酸不拆；\(\ce{NH4HCO3}\) 是可溶强电解质，拆成 \(\ce{NH4+}\) 和 \(\ce{HCO3-}\)。\(\ce{NH4+}\) 不与 \(\ce{CH3COOH}\) 反应，只有 \(\ce{HCO3-}\) 与 \(\ce{H+}\) 反应，生成 \(\ce{CO2}\) 和 \(\ce{H2O}\)。

注意：生成物中 \(\ce{NH4+}\) 和 \(\ce{CH3COO-}\) 都是旁观离子，不写进方程式。

第 \(14\) 题 答案：\(\ce{NH4+ + H+ + SO4^2- + Ba^2+ + 2OH- -> NH3.H2O + BaSO4 v + H2O}\)

关键：「刚好沉淀完全」= \(\ce{Ba^2+}\) 与 \(\ce{SO4^2-}\) 恰好按 \(1:1\) 完全反应，此时 \(\ce{Ba(OH)2}\) 加入的量按 \(\ce{Ba^2+}\) 计算。

\(1\) 个 \(\ce{Ba(OH)2}\) 提供 \(1\) 个 \(\ce{Ba^2+}\) 和 \(2\) 个 \(\ce{OH-}\)。\(2\) 个 \(\ce{OH-}\) 中，\(1\) 个先中和 \(\ce{H+}\)（来自 \(\ce{HSO4-}\) 电离），剩余的 \(1\) 个 \(\ce{OH-}\) 与 \(\ce{NH4+}\) 反应生成 \(\ce{NH3.H2O}\)（不是 \(\ce{NH3 ^}\)，因为稀溶液不加热）。

第 \(15\) 题 答案：\(\ce{Ca^2+ + OH- + HCO3- -> CaCO3 v + H2O}\)

\(\ce{Ca(OH)2}\) 溶液与 \(\ce{Ca(HCO3)2}\) 溶液任意比混合，说明 \(\ce{OH-}\) 和 \(\ce{HCO3-}\) 恰好按 \(1:1\) 完全反应，最终生成 \(\ce{CaCO3}\) 沉淀和水。

这是一个「任意比」题型的标准答案——只需写出最简的 \(1:1\) 形式。

第 \(16\) 题 答案：\(\ce{2Na+ + CO3^2- + H2O + CO2 -> 2NaHCO3 v}\)

易错点：\(\ce{Na2CO3}\) 是饱和溶液，通入足量 \(\ce{CO2}\) 后生成的 \(\ce{NaHCO3}\) 溶解度更小、会析出沉淀，所以要用「↓」符号表示 \(\ce{NaHCO3}\) 沉淀。

\(\ce{NaHCO3}\) 是强电解质，正常情况应拆成离子；但因为这里生成了固体沉淀，所以要写化学式并加 ↓。

第 \(17\) 题 答案： ① \(\ce{2H+ + SO4^2- + Ba^2+ + 2OH- -> BaSO4 v + 2H2O}\) ② \(\ce{SO4^2- + Ba^2+ -> BaSO4 v}\)

① 混合至中性：\(\ce{NaHSO4}\) 中的 \(\ce{H+}\) 恰好被 \(\ce{Ba(OH)2}\) 中的 \(\ce{OH-}\) 完全中和，此时 \(\ce{SO4^2-}\) 还有剩余（因为 \(\ce{NaHSO4}\) 是 \(1:1\) 提供 \(\ce{H+}\) 和 \(\ce{SO4^2-}\)，中和 \(2\) 个 \(\ce{H+}\) 只需 \(1\) 个 \(\ce{Ba^2+}\)，多余的 \(\ce{SO4^2-}\) 留在溶液中）。

② 继续滴加 \(\ce{Ba(OH)2}\)：溶液中剩余的 \(\ce{SO4^2-}\) 与新增的 \(\ce{Ba^2+}\) 结合生成 \(\ce{BaSO4}\) 沉淀，\(\ce{OH-}\) 无反应对象留在溶液中。

第 \(18\) 题 答案：\(\ce{Cu2(OH)2CO3 + 4H+ -> 2Cu^2+ + CO2 ^ + 3H2O}\)

碱式碳酸铜是难溶固体，写化学式、不拆；稀盐酸是强酸，拆成 \(\ce{H+}\)；生成的 \(\ce{CuCl2}\) 可溶，拆成 \(\ce{Cu^2+}\)；\(\ce{H2CO3}\) 分解为 \(\ce{CO2}\) 和 \(\ce{H2O}\)。

配平核对：左边 \(4\) 个 \(\ce{H+}\) → 右边 \(3\) 个 \(\ce{H2O}\)（\(6\) 个 \(\ce{H}\)，多出的 \(2\) 个 \(\ce{H}\) 来自 \(\ce{Cu(OH)2}\) 中的 \(\ce{OH}\)）；\(\ce{C}\) 守恒 \(1\) 个；\(\ce{Cu}\) 守恒 \(2\) 个；\(\ce{O}\) 守恒 \(3+2=5=3+2\) ✓。

第 \(19\) 题 答案：\(\ce{G < Y < Q < Z < X}\)

推理步骤：

① 由 \((3)\) \(\ce{Q + H2O -> X + H2 ^}\)，氯元素发生歧化，\(\ce{X}\) 的化合价 \(<\) \(\ce{Q}\) 的化合价，且 \(\ce{X}\) 是含氯的最低价物质，推测 \(\ce{X} = \ce{HCl}\)（\(-1\) 价）。

② 由 \((1)\) \(\ce{Y + NaOH -> G + Q + H2O}\)，这是 \(\ce{Cl2 + 2NaOH -> NaCl + NaClO + H2O}\) 的典型形式，所以 \(\ce{Y} = \ce{Cl2}\)（\(0\) 价），\(\ce{G} = \ce{NaClO}\) 或 \(\ce{HClO}\)（\(+1\) 价），\(\ce{Q}\) 是更高价态。

③ 由 \((2)\) \(\ce{G -> Q + NaCl}\)，\((4)\) \(\ce{Z + NaOH -> Q + X + H2O}\)，可推出 \(\ce{Q} = \ce{HClO3}\) 或 \(\ce{ClO3-}\)（\(+5\) 价），\(\ce{Z} = \ce{HClO4}\) 或 \(\ce{ClO4-}\)（\(+7\) 价）。

结论：

· \(\ce{Y} = \ce{Cl2}\)（\(0\) 价）
· \(\ce{G} = \ce{NaClO}\) 或 \(\ce{HClO}\)（\(+1\) 价）
· \(\ce{Q} = \ce{HClO3}\)（\(+5\) 价）
· \(\ce{Z} = \ce{HClO4}\)（\(+7\) 价）
· \(\ce{X} = \ce{HCl}\)（\(-1\) 价）

按题目要求由低到高排列（按原卷答案）：\(\ce{G < Y < Q < Z < X}\)。
