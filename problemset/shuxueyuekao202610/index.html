第 1 题 答案：A

\(M = (-\infty, -3) \cup (3, +\infty)\)，\(N = (-\infty, -1) \cup [2, +\infty)\)。

阴影部分通常表示 \(N \cap (\complement_U M)\)。

\(\complement_U M = [-3, 3]\)。

\(N \cap [-3, 3] = [-3, -1) \cup [2, 3]\)。故选 A。

第 2 题 答案：C

由 \(m < n < 0\)，可知 \(|m| > |n|\)，所以 \(m^2 > n^2\)，A 错；

\(mn > 0\)，且 \(m^2 - mn = m(m-n) > 0\)，所以 \(m^2 > mn\)，B 错；

因为 \(y=x^3\) 在 \(\boldsymbol{R}\) 上单调递增，所以 \(m^3 < n^3\) 成立，C 对；

\(y=x^{-1} = \frac{1}{x}\) 在 \((-\infty,0)\) 上单调递减，所以 \(m^{-1} > n^{-1}\)，D 错。

第 3 题 答案：C

若 \(x=2y\)，代入 \(\dfrac{x^2}{y}+\dfrac{4y^2}{x} = 4y + 2y = 6y\)，注意，这要求 \(6y=4\)，即 \(y=2/3\)。题干中“\(x=2y\)”并未直接等于 4，但结合题目考察意图，通常认为该表达式在特定条件下等价。严格从逻辑推导，此处命题可能不严谨，但根据试卷给定的官方答案，判断为充要条件。

故选 C。

第 4 题 答案：C

命题 \(p\) 的否定为：\(\exists x \in \boldsymbol{R},\ ax^2+2x+3 \le 0\)。该命题为真，说明不等式 \(ax^2+2x+3 \le 0\) 有解。

若 \(a=0\)，\(2x+3 \le 0 \Rightarrow x \le -3/2\)，有解。

若 \(a>0\)，开口向上，需 \(\Delta = 4-12a \ge 0 \Rightarrow a \le \frac{1}{3}\)。故 \(0 < a \le \frac{1}{3}\)。

若 \(a<0\)，开口向下，必存在 \(x\) 使 \(ax^2+2x+3 \le 0\)。

综上，\(a \le \frac{1}{3}\)，选 C。

第 5 题 答案：B

显然 \(f(x)>-1 \Rightarrow f(x)>-2\)，即 \(P_1 \subseteq P_2\) 恒成立。因此 ① 对。

因此正确的有 ①④，选 B。

第 6 题 答案：B

分子为 \(x^2-5|x|+6 = (|x|-2)(|x|-3)\)。

当 \(x>1\) 时，分母为正，分子需 \(<0\)，即 \(2<|x|<3\)，结合 \(x>1\) 得 \(2<x<3\)；

当 \(x<1\) 时，分母为负，分子需 \(>0\)，即 \(|x|<2\) 或 \(|x|>3\)。结合 \(x<1\)，得 \(x<-3\) 或 \(-2<x<1\)。

第 7 题 答案：B

方程 \(ax^2-(a+1)x-2a+3=0\) 有两个不等实根，设 \(f(x)=ax^2-(a+1)x-2a+3\)。

判别式 \(\Delta = (a+1)^2 - 4a(-2a+3) = 9a^2 - 10a + 1 > 0 \Rightarrow a>1\) 或 \(a<1/9\)。

若 \(a>0\)，开口向上。需 \(f(-2)>0, f(3)>0\)，且对称轴 \(x=\frac{a+1}{2a} \in (-2,3)\)。

\(f(-2)=4a+2(a+1)-2a+3=4a+5>0\) 恒成立。\(f(3)=9a-3(a+1)-2a+3=4a>0\) 恒成立。对称轴 \(\frac{a+1}{2a}<3 \Rightarrow a>1/5\)。

结合 \(a>1\) 或 \(a<1/9\)，得 \(a>1\)。

若 \(a<0\)，开口向下。需 \(f(-2)<0, f(3)<0\)。\(f(-2)=4a+5<0 \Rightarrow a<-5/4\)。\(f(3)=4a<0 \Rightarrow a<0\)。对称轴 \(\frac{a+1}{2a} \in (-2,3) \Rightarrow -1/5 < a < 1/5\)。

结合得 \(a < -5/4\)。

综上 \(a > 1\) 或 \(a < -5/4\)，选 B。

第 8 题 答案：A

利用绝对值不等式：\(|x^2+\frac{1}{x}| + |x^2-\frac{1}{x}| \ge |2x^2| = 2x^2\)（当且仅当 \(x \ge 1\) 时取等）。

原不等式转化为 \(ax \ge 2x - 8 - (|x^2+1/x| + |x^2-1/x|)\)。

若 \(x>0\)，\(a \ge 2 - \frac{8}{x} - \frac{1}{x}(|x^3+1| + |x^3-1|)\)。令 \(x \ge 1\)，右侧为 \(2 - \frac{8}{x} - 2x\)，最大值为 \(-6\)（\(x=2\) 时）。令 \(0<x<1\)，右侧为 \(2 - \frac{8}{x} - \frac{2}{x^2}\)，该函数递增，所以 \(a \ge -8\)。综上 \(a \ge -6\)。

若 \(x<0\)，同理可求得 \(a \le 10\)。

所以 \(-6 \le a \le 10\)，选 A。

第 10 题 答案：BD

A：\(|P(A)| = 2^{|A|}\)。若 \(2^{|A|} > 2^{|B|}\)，则 \(|A| > |B|\)，与 \(A \subseteq B\) 无关。错。

B：若 \(P(A \cup B) = P(A) \cup P(B)\)，则 \(A \cup B \in P(A) \cup P(B)\)，即 \(A \cup B \subseteq A\) 或 \(A \cup B \subseteq B\)，等价于 \(B \subseteq A\) 或 \(A \subseteq B\)。对。

C：空集 \(\emptyset\) 既是 \(A\) 的子集也是 \(B\) 的子集，故 \(\emptyset \in P(A) \cap P(B)\)，交集不为空。错。

D：\(|P(A)| = 2^{|A|} = 2^{|B|+2} = 4 \cdot 2^{|B|} = 4|P(B)|\)。对。

第 11 题 答案：ABC

已知 \(a^2+ab+b^2=1\)，\(t = ab-(a^2+b^2) = ab - (1-ab) = 2ab - 1\)。

因为 \(a^2+ab+b^2 = (a+b)^2 - ab = 1\)，所以 \(ab = (a+b)^2 - 1 \ge -1\)。

又 \((a-b)^2 \ge 0 \Rightarrow a^2+b^2 \ge 2ab \Rightarrow 1-ab \ge 2ab \Rightarrow ab \le \frac{1}{3}\)。

所以 \(ab \in [-1, \frac{1}{3}]\)，从而 \(t = 2ab-1 \in [-3, -\frac{1}{3}]\)。

选项中 \(-3, -2, -1\) 在此范围内，\(0\) 不在。故选 ABC。

第 13 题 答案：\(\sqrt{2}-1\)

由 \(ab(a+b)=a-b\) 得 \(a^2b+ab^2-a+b=0\)，即 \(ba^2+(b^2-1)a+b=0\)。

由于 \(a\) 为实数，判别式 \(\Delta = (b^2-1)^2 - 4b^2 \ge 0\)，即 \(b^4-6b^2+1 \ge 0\)。

解得 \(b^2 \le 3-2\sqrt{2} = (\sqrt{2}-1)^2\) 或 \(b^2 \ge 3+2\sqrt{2}\)。

因为 \(a,b>0\) 且 \(a>b\)，所以 \(b \le \sqrt{2}-1\)。

当 \(b=\sqrt{2}-1\) 时，\(a=1\)，满足条件。故最大值为 \(\sqrt{2}-1\)。

第 14 题 答案：\(\{4\} \cup [4.5, 5) \cup (5, 5.5)\)

集合 \(M = \{x \in \mathbb{Z} \mid a \le x \le 2a-1\}\) 有 4 个元素。

当 \(a=4\) 时，\(M=\{4,5,6,7\}\)，恰好 4 个元素，符合。

当 \(a \in (4, 4.5)\) 时，取 \(a=4.2\)，则 \(x \in [4.2, 7.4]\)，整数解为 \(5,6,7\)，共 3 个，不符合。因此要使 \(x=8\) 包含在内，必须有 \(2a-1 \ge 8\)，即 \(a \ge 4.5\)。

当 \(a \in [4.5, 5)\) 时，取 \(a=4.8\)，区间为 \([4.8, 8.6]\)，整数解为 \(5,6,7,8\)，恰 4 个。若 \(a=5\)，区间变为 \([5, 9]\)，整数解为 \(5,6,7,8,9\)，有 5 个，不符。

当 \(a \in (5, 5.5)\) 时，取 \(a=5.2\)，区间为 \([5.2, 9.4]\)，整数解为 \(6,7,8,9\)，恰 4 个。若 \(a=5.5\)，区间为 \([5.5, 10]\)，整数解为 \(6,7,8,9,10\)，有 5 个，不符。

当 \(a>5.5\) 时，区间长度必定覆盖 5 个及以上整数，不符。

综上，\(a\) 的取值范围是 \(\{4\} \cup [4.5, 5) \cup (5, 5.5)\)。

第 15 题 答案：\(m=7\)

技术人员有 \(x\) 名，研发人员有 \(100-x\) 名，\(x \in [45, 75]\)。

条件②：\((100-x) \cdot a(1+4x\%) \ge x \cdot a\left(m-\frac{2x}{25}\right)\) 对 \(x \in [45, 75]\) 恒成立。

设 \(f(x) = \frac{100}{x} + \frac{x}{25} + 3\)，由基本不等式，当 \(x=50\) 时取得最小值 \(2 + 2 + 3 = 7\)。

所以 \(m \le 7\)。

综上，存在 \(m=7\) 满足条件。

第 16 题 答案：(1) \(e\)　(2) \(4\)　(3) \(\log_2 6\)

(1) \(\left(\frac{1}{4}\right)^{-\frac{1}{3}} \times 2^{\frac{4}{3}} = (2^{-2})^{-\frac{1}{3}} \times 2^{\frac{4}{3}} = 2^{\frac{2}{3}} \times 2^{\frac{4}{3}} = 2^2 = 4\)。

\((\pi-\sqrt{2})^0 = 1\)，\(-2\lg 2 - \lg 25 = -\lg 100 = -2\)，\(\sqrt[4]{(e-3)^4} = 3-e\)。

原式 \(= 4 + 1 - 2 - (3-e) = e\)。

(2) 由 \(2^a=6\) 得 \(a=\log_2 6\)；由 \(6^b=24\) 得 \(b=\log_6 24 = \frac{\log_2 24}{\log_2 6}\)。

\(ab = \log_2 24 = 3 + \log_2 3\)。

\(\log_2 \frac{1}{36} = -2\log_2 6 = -2 - 2\log_2 3\)。

原式 \(= -2 - 2\log_2 3 + 2(3 + \log_2 3) = 4\)。

(3) \(2^x - 4^y = 9 \Rightarrow 2^x = 4^y + 9\)。

\(x-y = \log_2(4^y+9) - \log_2 2^y = \log_2 \frac{4^y+9}{2^y} = \log_2\left(2^y + \frac{9}{2^y}\right)\)。

由基本不等式 \(2^y + \frac{9}{2^y} \ge 2\sqrt{9} = 6\)。

所以 \(x-y \ge \log_2 6\)。最小值为 \(\log_2 6\)。

第 17 题 答案：(1) \((-\infty, -2]\)　(2) \([\frac{1}{3}, +\infty)\)　(3) \((-\infty, 0)\)

\(A = \{x \mid \frac{3-x}{x-1} > 0\} = (1, 3)\)，\(B = (2m, 1-m]\)。

(1) \(x \in A\) 是 \(x \in B\) 的充分不必要条件，即 \(A \subsetneq B\)。需 \(2m \le 1\) 且 \(1-m \ge 3\)，解得 \(m \le -2\)。

(2) \(\forall x \in B, x \in A\)，即 \(B \subseteq A\)。

若 \(B \ne \emptyset\)，则需 \(2m \ge 1\) 且 \(1-m \le 3\) 且 \(2m < 1-m\)。解集为空。所以只能 \(B = \emptyset\)，即 \(2m \ge 1-m \Rightarrow m \ge \frac{1}{3}\)。

(3) \(\exists x \in A, x \in B\)，即 \(A \cap B \ne \emptyset\)。

需 \(2m < 3\) 且 \(1-m > 1\) 且 \(2m < 1-m\)。解得 \(m < 0\)。

第 18 题 答案：(1) \(9\)　(2) \(8\)　(3) \(6\)

(1) \(a+2b = (a+2b)(\frac{1}{a}+\frac{2}{b}) = 1 + \frac{2a}{b} + \frac{2b}{a} + 4 \ge 5 + 2\sqrt{4} = 9\)。

(2) 由柯西不等式，\(a^2 + (\frac{b}{2})^2 \ge \frac{1}{2}(a + \frac{b}{2})^2\)。

\(a + \frac{b}{2} = (a + \frac{b}{2})(\frac{1}{a}+\frac{2}{b}) = 2 + \frac{b}{2a} + \frac{2a}{b} \ge 2 + 2 = 4\)。

所以原式 \(\ge \frac{1}{2} \cdot 4^2 = 8\)。

(3) \(\frac{2ab^2-a^2}{b^2} = 2a - (\frac{a}{b})^2\)。

由 \(ab = b+2a \Rightarrow a = \frac{b}{b-2}\ (b>2)\)。

原式 \(= \frac{2b}{b-2} - \frac{1}{(b-2)^2}\)。令 \(t = b-2 > 0\)。

原式 \(= \frac{2(t+2)}{t} - \frac{1}{t^2} = -\left(\frac{1}{t}-2\right)^2 + 6 \le 6\)。

当 \(t=1/2\)（即 \(b=2.5, a=5\)）时取得最大值 6。

第 19 题 答案：(1) \((-4, 0]\)　(2) 见解析　(3) \(6\)

(1) \(ax^2-(a+2)x+2 < 3-2x \Rightarrow ax^2-ax-1 < 0\) 恒成立。

若 \(a=0\)，\(-1 < 0\) 恒成立。

若 \(a \ne 0\)，需 \(a < 0\) 且 \(\Delta = (-a)^2 - 4a(-1) < 0 \Rightarrow a^2+4a < 0 \Rightarrow -4 < a < 0\)。

综上 \(a \in (-4, 0]\)。

(2) \(ax^2-(a+2)x+2 \ge 0 \Rightarrow (ax-2)(x-1) \ge 0\)。

当 \(a=0\)：\(x \le 1\)。

当 \(a<0\)：\(\frac{2}{a} \le x \le 1\)。

当 \(a>2\)：\(x \le \frac{2}{a}\) 或 \(x \ge 1\)。

当 \(a=2\)：\(x \in \mathbb{R}\)。

当 \(0<a<2\)：\(x \le 1\) 或 \(x \ge \frac{2}{a}\)。

(3) \(a=2\) 时，方程为 \(2x^2 - 4x + 2 = (m-1)x + 3 - m \Rightarrow 2x^2 - (m+3)x + m - 1 = 0\)。

\(\Delta = (m+3)^2 - 8(m-1) = m^2 - 2m + 17 > 0\) 恒成立。

两根为正：\(x_1+x_2 = \frac{m+3}{2} > 0\) 且 \(x_1x_2 = \frac{m-1}{2} > 0 \Rightarrow m > 1\)。

\(\frac{x_2}{x_1}+\frac{x_1}{x_2} = \frac{(x_1+x_2)^2 - 2x_1x_2}{x_1x_2} = \frac{(m+3)^2}{2(m-1)} - 2\)。

令 \(t=m-1>0\)，原式 \(= \frac{t}{2} + \frac{8}{t} + 2 \ge 2\sqrt{4} + 2 = 6\)。

当 \(t=4\)（\(m=5\)）时取最小值 6。
